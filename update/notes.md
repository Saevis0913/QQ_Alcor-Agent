## 本次更新

0.3.2-as.7 小版本（内核 0.4.4）

这一版把最近修的东西都合到一个包里：
1) 注入后自动找回消息服务对象：QQ 已经建过消息服务、只是没挂到全局时，核心会扫描内存把它接回来（每 45 秒重试一次，最多 8 次），成功后自动从「只用身份」升级为原生收发，不用手动重连。
2) 宿主运行库跟着一起搬：安装路径含中文或很长时，宿主以前会因为找不到 runtime 子目录里的运行库而报 LB_HOST_IO（表现是已连接但收发全失败），现在整目录同步，不再受路径影响。
3) 收件修复：会话切换后第一条私聊不再被判成「已处理」丢掉；同一条消息重复到达只发布一次（这是 Issue #2 里 events 恒 0 的一类原因）。
4) 新结论 SERVICE_NEVER_CREATED：把「服务对象只是没挂上（能自动找回）」和「QQ 根本没建过服务对象（找回也没用）」分开说，后者直接建议改用 OneBot，不再让人反复重装重连。
5) 入站证据：解不出来的推送会记录消息类型和「是不是自己发出的回执」，诊断里能区分「自己消息的回执」与「别人发来但没解析出来」。
6) 环境取证：进程快照带命令行、父进程、安装盘符与盘型；系统登记里已经卸载的杀软残留不再被当成「装了第三方杀软」报警（只出一条 info 说明这是残留登记）。
7) 消息服务确实拿不到的机器，诊断卡片可以一键改用 OneBot 接入：填 HTTP/WS 地址和令牌，先「测试连接」确认通了再切，随时能切回内置核心。
8) 内置核心版恢复到原生界面：不再被误渲染成「OneBot 连接」表单。
9) 更新只提示、不自动装（从上个版本延续）：发现新版本弹一次提示，点「立即更新」才下载安装，点「暂不更新」本次启动不再打扰。
10) 安装器升级结束如果 QQ 被关掉，会自动把它重新拉起来。

从 0.3.2 / 0.3.2-as.1 ~ as.6 都会提示升到 0.3.2-as.7；装完自动回到界面。
