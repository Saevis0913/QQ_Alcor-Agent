## 开发目的

此前一直关注并使用开源项目 SnowLuma 进行学习与实验。在 SnowLuma 创作者收到腾讯律师函并将仓库转为私有后，为了延续个人的技术探索与日常使用需求，决定汲取相关经验，动手构建一套更轻量、更贴合个人使用习惯的全新接入框架 **Alcor**，并在此基础上编写了主打低门槛与易用性的智能体程序 **Alcor Agent**。

## 项目简介

本项目由底层协议接入框架 **Alcor** 与上层智能体应用 **Alcor Agent** 协同驱动，致力于以**低门槛、易上手、轻量化**的方式打通大语言模型与 QQ 即时通讯生态：

* **Alcor**：基于 NapCat 与 SnowLuma 的设计经验重新开发的 QQ 接入框架，专注于简化配置流程与降低部署门槛，提供清晰的消息收发、事件分发与账号状态管理能力。
* **Alcor Agent**：运行在 Alcor 框架之上的 AI 智能体核心，集成意图决策、记忆管理、插件调度与可视化数据查询，让 AI 能够以自然拟人的方式操作 QQ 账号进行日常聊天。

## 核心特性

* **简单易上手，开箱即用**：摒弃繁琐的配置与复杂依赖，致力于让新手也能在短时间内完成部署并跑通完整的 QQ AI 对话流程。
* **纯粹免费，零内购**：项目本体完全免费提供，不包含任何功能付费墙、会员订阅或隐藏内购项目（用户仅需自备合规的大模型 API 密钥即可运行）。
* **极简插件与 Skill 扩展**：提供极其直观、低上手门槛的自定义插件（Plugin）与技能（Skill）接入机制，无需复杂脚手架即可快速赋予 AI 联网查询、群管自动化或外部工具调用等新能力。
* **高度可定制的 AI 人设**：支持灵活配置角色设定、语言风格与行为边界，轻松打造贴合特定群聊氛围或个人偏好的专属智能体形象。
* **运行数据清晰可查**：内置完善的透明化查询能力，支持随时查看详细的 **API 用量信息**、完整的**历史会话记录**以及结构化的 **AI 记忆存档**，让每一次模型调用与记忆演变都有迹可循。
* **协议与智能双层解耦**：底层通信（Alcor）与上层逻辑（Alcor Agent）独立分层，结构清晰，方便后续扩展与二次开发。

## 快速开始

1. 安装正式版安装包（Windows x64），或按下文的开发方式从源码运行。
2. 首次启动后打开控制台 `http://127.0.0.1:5320`，在 **设置 → 模型与联网** 填入自己的大模型 API 地址与密钥，保存后点「测试连通性」。
3. 在 **设置 → 聊天与人格** 写好人设、管理员 QQ、聊天白名单与回复档位。
4. 在 **设置 → 连接与桌面** 连接 OneBot / 启动内置 Alcor 核心，即可开始收发消息。

开发运行（需要 Node 22+）：

```bash
cd resources/app
npm install
npm start
```

## 控制台显示「无法连接 / 被占用」怎么办

程序不自带任何第三方框架（NapCat、SnowLuma、LiteLoader 都不在包里，见 `resources/alcor/native-core/discovery.mjs` 只做识别）。遇到连不上，双击安装目录里的：

`控制台无法连接，显示被占用点这个，对照最后一行判定码.cmd`

它只读地扫一遍本机，**最后一行判定码**按下面的表处理：

| 判定码 | 含义 | 处理 |
| --- | --- | --- |
| `UNSUPPORTED_BUILD` | QQ 版本不支持 | 原生接入按 `wrapper.node` 的 SHA-256 精确匹配，当前只适配 `9.9.36-53644` 与 `9.9.37-54395`。换回这两个版本之一；QQ 自动更新后需要等新版本适配 |
| `HOST_PRESENT` | 上次注入的宿主还驻留在 QQ 里 | 退出 QQ 重新登录，或点设置页的「重启 QQ 后重试」 |
| `FOREIGN_MODULES` | 有其他框架占用 | 同一个号只能接入一个框架；退出 LiteLoaderQQNT / NapCat / LLOneBot / SnowLuma 等，报告会列出具体模块名 |
| `CORE_OFFLINE` | Alcor 核心没在运行 | 先启动 Alcor 核心（侧栏「Alcor」页可启动），再回到设置页点「连接 QQ」 |
| `NO_QQ_RUNNING` | 没检测到 QQ 进程 | 先登录 QQ |
| `RECEIVE_NOT_READY` | 宿主连上了，账号或消息通道还没确认 | 在 QQ 里确认已登录，点「重新扫描」；一直不恢复就重启 QQ 再连 |
| `READY_TO_CONNECT` | 一切就绪 | 点设置 → 连接与桌面 → 「连接 QQ」 |
| `ALREADY_CONNECTED` | 已连接 | 无需处理 |

同一份判定也显示在 **设置 → 连接与桌面 → QQ 接入** 卡片上，底栏状态会写成「QQ 版本未适配」「QQ 可以连接」这类短语。报告同时落盘在 `data/qq-doctor-<时间戳>.log`。

## 版本

当前源码快照对应 **Alcor Agent 0.2.3**（正式版安装包 `Alcor-Agent-Setup-0.2.3-x64.exe`）。

本版要点：图片与表情共用一条转发路径（可按消息转发、随时收藏）、已收表情单独发送、API 认证失败与额度不足的明确错误码、设置页五栏分类与账本式排版、右侧抽屉式弹窗、思考强度六挡滑杆（轻度/中/高/极高/max/Ultra）。
