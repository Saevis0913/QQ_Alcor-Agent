# Alcor 原生能力边界

当前链路为 Alcor Agent → Alcor 自有原生核心 → 官方 QQ 真人账号，不使用官方机器人账号接口。

本阶段实际验证的是指定私聊的文字发送与接收，以及账号、状态、版本和本次服务消息缓存查询。媒体、群消息/群管理、完整联系人、跨重启历史、反向推送、多账号和自动重连仍有未实现或未完成验收的部分。

动作目录列出名称不等于这些动作已经实现。Agent 提供按钮或 OneBot 客户端方法，也不等于当前核心已支持对应能力。开发扩展前检查当前核心 `/health`、控制台能力状态及具体动作返回值。遇到未实现能力要明确说明，并提供有界降级，不要伪造成功响应。

QQ 接口适配与客户端调用可阅读 `src/onebot.js`；工具调用上下文应按 `src/orchestrator.js` 和目标工具实现确认。不要从其他平台文档猜当前 API。

测试优先使用本地模拟数据，禁止为验证扩展而默认群发或重发未知结果的消息。需要真实发送时使用用户授权的会话和账号；接收端确认与服务器接受要分别记录。此说明不保证平台长期兼容或账号始终免于限制。
