    OneBot 监听配置

    Alcor 提供 OneBot 11 HTTP 接口和正向 WebSocket 事件接口。

    127.0.0.1 和 ::1 分别为 IPv4 与 IPv6 回环地址。 允许 1 至 65535。

    配置在重启 Alcor 核心后生效。

    事件回调与反向连接

    将收到的事件推送给你配置的服务。仅本机地址允许 HTTP / WS，其他地址须使用 HTTPS / WSS。默认不启用。

    HTTP 事件回调

    反向 WebSocket

    反向连接支持接收事件和调用动作。回调失败不自动重发，防止对接服务重复回复。保存后重启核心生效。

    接入 Alcor Agent

    将当前运行的地址和访问令牌填入 Alcor Agent 的 OneBot 设置。切换前暂停旧 Agent 的自动回复，以防重复回复。
